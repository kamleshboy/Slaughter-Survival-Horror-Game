# 🔪 Slaughter

**A first-person survival horror game inspired by Granny.**

Slaughter is a horror game where players must explore their surroundings, solve puzzles, find useful items, and escape while avoiding a dangerous enemy. Stay quiet, think strategically, and be careful with every move you make.

## 🎮 About the Game

Slaughter is a horror project developed as a school project. It takes inspiration from classic escape-room horror games, combining exploration, puzzle-solving, stealth, and suspense.

Your objective is simple: **survive and find a way out.**

## ✨ Features

- 🏚️ Atmospheric horror environment
- 🔑 Exploration and item collection
- 🧩 Puzzles and escape mechanics
- 👂 Stealth-based gameplay
- 😱 Suspenseful encounters
- 🎮 Survival horror inspired by Granny

*Features may vary depending on the current version of the game.*

## 🕹️ How to Play

1. Explore your surroundings.
2. Search for useful items.
3. Solve puzzles to unlock your path.
4. Avoid the enemy and stay alert.
5. Find a way to escape.

## 🚀 Getting Started

1. Open this repository.
2. Download or clone the project.
3. Follow the setup instructions for the game's engine and dependencies.
4. Launch the game using the appropriate project files.
